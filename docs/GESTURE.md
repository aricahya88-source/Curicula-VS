# Gesture Curicula-VS

## Pilihan Ganda
- ☝️ = A
- ✌️ = B
- 🤟 = C
- ✋ = D
- ✊ tahan = Kunci

## Benar / Salah
- ☝️ A = Benar
- ✌️ B = Salah
- ✊ tahan = Kunci

## Menjodohkan
- Arahkan tangan ke kartu
- Pinch untuk mengambil
- Geser ke kotak pasangan
- Lepas pinch untuk menaruh
- ✊ tahan = Kunci

## Pilihan Lebih dari 1
- ☝️ = toggle A
- ✌️ = toggle B
- 🤟 = toggle C
- ✋ = toggle D
- Ulangi gesture opsi yang sama untuk membatalkan
- ✊ tahan = Kunci
