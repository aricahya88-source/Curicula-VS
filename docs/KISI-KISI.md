# Kisi-kisi Curicula-VS

Materi utama:
1. Hakikat dan fungsi kurikulum.
2. Komponen kurikulum: tujuan, isi, proses, evaluasi.
3. Prinsip pengembangan kurikulum: relevansi, fleksibilitas, kontinuitas, efektivitas.
4. Implikasi kurikulum terhadap pembelajaran fisika.
5. Perkembangan kurikulum mulai KTSP 2006, Kurikulum 2013, Kurikulum Merdeka, dan penyesuaian kebijakan 2025.

Setiap soal menggunakan narasi literasi 3–4 kalimat yang langsung dilanjutkan pertanyaan, tanpa label stimulus/pertanyaan pada antarmuka.
